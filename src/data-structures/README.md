# Data Structures Workshop

Build each structure from scratch before using it in the interview problems.
Decide and document the behavior for empty operations, duplicate values, and
invalid input.

| Structure | Operations to implement |
| --- | --- |
| [Linked List](./linked-list.js) | prepend, append, find, remove |
| [Stack](./stack.js) | push, pop, peek, size |
| [Queue](./queue.js) | enqueue, dequeue, peek, size |
| [Min Heap](./min-heap.js) | insert, peek, extract minimum |
| [Binary Search Tree](./binary-search-tree.js) | insert, contains, remove, traverse |
| [Trie](./trie.js) | insert, search, prefix search |
| [Union-Find](./union-find.js) | find, union, connected, component count |
