# Complexity Analysis

Complexity is the language used to compare every solution in this repository.
For each problem, write down:

1. The input size variable you are measuring.
2. The dominant time cost in the worst case.
3. Auxiliary space, separate from required output space.
4. Whether recursion adds call-stack space.
5. Which tradeoff an alternative approach would make.

Useful growth rates to recognize are O(1), O(log n), O(n), O(n log n),
O(n^2), O(2^n), and O(n!).

Do not optimize from the label alone. First explain which operations produce
the cost and why the stated bound is valid.
